# Algorithm Workbench Exercises

1. Modify binary search to return the rightmost duplicate.
2. Compare insertion sort and merge sort on already-sorted input.
3. Change BFS to return a distance rather than a path.
4. Explain why Dijkstra's algorithm rejects negative weights.
5. Extend coin change to return the actual coins selected.
6. Compare the (O(n^2)) LIS implementation with a patience-sorting approach.
7. Add sample variance with denominator (n-1) while keeping population variance separate.
8. Change word counting to ignore a configurable stop-word list.
9. Extend DisjointSet with a count of current connected components.
10. Re-run the benchmark for multiple random seeds and record how stable the ratios are.

For each extension, add at least one test for a boundary condition.
