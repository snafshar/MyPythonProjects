# Python Collections Lab

Practice these standard-library tools:

- `Counter` for frequencies.
- `defaultdict(list)` for grouping.
- `deque` for queues.
- `heapq` for priority queues.
- `set` for uniqueness and membership checks.

Exercises:
1. Count words case-insensitively.
2. Group records by a field.
3. Implement a FIFO queue using `deque`.
4. Find the three largest values with `heapq.nlargest`.
5. Compare list membership and set membership for repeated lookups.

Prefer clear data structures over clever one-liners.
