# AlgoKit: Small Algorithm Practice

A dependency-free collection of beginner-friendly algorithms with clear input contracts.

## Run

```bash
python3 algokit.py
python3 -m unittest -v
```

The examples cover binary search on sorted data, frequency counting, and checking balanced brackets. Each function is designed to be independently reusable.

## Suggested extensions

- Add a linear-search implementation and compare it with binary search.
- Measure runtime for increasing input sizes.
- Add randomized tests against a simple reference implementation.
