# Python Practice Pack

Small, dependency-free utilities for learning Python CLI design, file handling, and testing.

- `path_report.py`: inventory a directory tree.
- `ini_inspect.py`: inspect INI sections and keys.
- `datetime_tools.py`: parse ISO timestamps and normalize to UTC.
- `dict_merge.py`: merge configuration dictionaries with clear precedence.
- `collections_examples.py`: grouping and frequency patterns.
- `tests/`: deterministic unit tests.

Run a script with Python 3.10+ and run tests from this directory with `python3 -m unittest discover -s tests -v`.
